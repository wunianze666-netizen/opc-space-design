# 园区总平面

园区先明确地块边界、现状与新建建筑、主入口、各建筑入口、道路宽度和功能分区。根据用户希望的用途组织空间，补充公共活动、停留、维护与交通需求。地形、管线和控制条件应按实际资料处理。

使用 [园区示例](../examples/campus/campus.json) 构造输入，坐标及建筑高度统一为毫米。建筑用 `existing` 或 `proposed` 标注。道路为中心线和宽度。建筑入口位于建筑外轮廓，园区入口位于地块边界。缺少确认的尺度、入口或建筑高度时先整理待核信息。

```sh
python scripts/run.py campus examples/campus/campus.json --out ./campus-demo
```

交付包含园区总平面 PNG、建筑体量三维 PNG、毫米 DXF 和园区核对 JSON。DXF 按地界、建筑、功能分区、路径范围和入口分层。脚本检查地界、建筑和道路的二维关系，并依据已输入道路判断建筑入口是否与园区入口相连。断开时返回 `needs_revision`，先调整路线再给出方案。

园区体量图表示输入建筑的轮廓与高度。建筑立面、室内、景观细部、道路坡度、消防、车行、无障碍和管线按现场数据和专业方案深化。对单栋建筑的单层内部，沿用 [整层办公](whole-floor.md) 的单层几何校核范围。多栋多层分别生成室内方案，并在园区总平面中保留楼栋和入口对应。
