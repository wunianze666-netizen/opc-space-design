# 原创设计方法

用户有具体想法时，从原话抓出要保留的场景、材质、物件和感受。用户让你推荐时，先用人的动作写出设计目标。例如「下班回来有个地方坐着看十分钟书」比「做一个科技感的家」更能指导设计。

1. 找出这个场地特有的条件。入口第一眼、经过的视线、停留的声音、原材料和不能移动的构件，都可以成为方案的依据。
2. 需要比选时，拟两条真正不同的方向。每条说明进门会看见什么、如何使用、墙地顶怎样组合及维护成本。可以借用用户的行业、习惯或场地环境形成图形语言。把色卡和库里的元素当作素材。允许提出新的平面墙艺、尺寸明确的定制物件和原创图案，具体外形及性能按可表达能力呈现。
3. 把采用的想法落实到一个焦点和几处支持它的构件。交代材料、位置、实际尺寸、灯光和开启方向。画面上留足看清门洞、走线和主要家具的位置。重点小物用局部图加编号。主题、文字和纹样应跟随实际位置。
4. 让用户看一份整区平面和同坐标三维，并用短句讲清推荐理由。对比时把两张图放在同一视角。核对原创构件与源布局、窗和通道的关系。用户已确认的标志文字用准确排版。

可以用生图制作正视、可重复或整幅的饰面图。也可以在整区说明里用 `artwork` 写出你设计的图层，渲染器会把它按毫米映射到所选墙地。需要自由曲线时，可用归一化折线采样或调用宿主可用的矢量、CAD 或 Blender 工具。技术图沿用已校核坐标，氛围参考按概念呈现。
