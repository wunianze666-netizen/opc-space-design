# 饰面纹样与试铺

先确定哪块墙面或地面值得用图案，以及图案怎样支持这处活动。科技办公可把蓝灰几何线纹集中在展示背景，简约住宅可把暖亚麻细线留在起居焦点，绿化风格可用浅苔绿叶纹与定向橡木纹。库中模块尺寸可作为比较起点，随后按已建模表面、主要视线、收口位置和样品调整。

1. 选定墙面或地面，描述基底、色差、纹样大小、走向、表面光泽和收边。湿区、入口和高流量地面另查清洁、防滑、基层与完成面条件。保留地面或墙面时，可以在可移动的软装上表达风格。
2. 可选用宿主的生图工具，提供平视、无透视、等光照的单元图要求，说明边缘是否接续。保留原始图、完整提示词和采用的毫米重复尺寸。单元图也可以来自用户给的已确认材质小样。先看边缘接缝和远近尺度，再决定是否采用。
3. 从选定方案的 `整区物件.json` 查饰面编号。把纹样放在整区说明的 `patterns`，墙面与地面均引用本版已有的 D 编号。可用短说明写明起铺方向及实际选材待核项。

```json
{
  "patterns": [
    {
      "ref": "D004",
      "name": "暖燕麦亚麻线纹",
      "asset": "纹样/亚麻线纹.png",
      "repeat_mm": [300, 300],
      "note": "起居焦点面，先核实体样板与四边收口。"
    }
  ]
}
```

运行 `overview --brief` 或 `deliver --brief`。图片使用说明文件同目录内的相对路径，支持单张 PNG、JPEG、WebP。也可把 `asset` 换为 `artwork` 自绘原图。两者均省略时保留待确认项。每个构件绑定一个纹样。

## 自绘墙地纹样

```json
{
  "background": "#263D42",
  "layers": [
    {"shape": "ellipse", "points": [[0.68, 0.13], [0.87, 0.40]], "color": "#C88E64"},
    {"shape": "line", "points": [[0.06, 0.75], [0.32, 0.61], [0.58, 0.38], [0.92, 0.59]],
     "stroke": 0.008, "color": "#D5BB9C"}
  ]
}
```

`artwork` 使用左上原点和 0 至 1 归一化坐标。可叠加 `rect`、`ellipse`、`line` 和 `polygon`。矩形和椭圆用左上、右下两点，线宽为短边比例。画布比例取 `repeat_mm`。用主题自绘构图，壁画采用整幅模式，重复材料复核四边的接续。字标可另外使用 `brand_wall.py`。

墙面试铺按构件宽高和矩形正视图计算。地面按毫米外接范围重复，再沿真实地面多边形裁切。墙面从室内视角左上、地面从图纸外接范围左上开始。实际施工起铺线由铺排和收边确定。比较顺铺与横铺时，分别准备按方向排正的单元图并设对应宽高。

## 让图案进入三维

1. 先确认底图、开口和要保留的设施。墙纸或图形建为实际安装范围内的平面墙艺 `art`，铺地建为 `floor_finish` 多边形。墙厚、突出量、底顶标高均取方案输入。顶面按可证实的高度、已布置的灯体及构件表现。没有机电资料时注明吊顶接口待核。
2. 重复材料默认 `mode: "repeat"`。公司字样、导视和完整壁画用 `mode: "single"`，`repeat_mm` 填表面实际宽高，图片长宽比须与表面匹配至 1% 以内。生图可提供底纹或无字图形，品牌名称和标志用已确认文本及原文件排版。未提供真实字标时标记演示字样，发出前确认拼写、授权和视觉大小。项目风格可选 `石墨科技`，配温灰、石墨、铜色点缀。对比方案要改变重点墙、地面或顶灯的搭配，并交代为什么这样安排。
3. 对每套使用已通过 `verify` 的方案包。需要同图对照时保持底图一致，使用相同 `--azimuth` 和项目内的人视机位。局部人视的视线覆盖重点墙、地面和顶灯。开口、布局和物件的尺寸可从 DXF 与整区物件索引交叉核对。

有正式字标时优先使用用户提供的源文件。想快速试一张可换字的排版，可运行如下命令。输出作为 `mode: "single"` 资产使用。

```powershell
python scripts/brand_wall.py --brand "NORTHLIGHT" --subtitle "北辰设计实验室" --width-mm 1850 --height-mm 1530 --out "纹样/品牌墙.png"
```

```powershell
python scripts/run.py overview <方案包> --option A --brief <整区说明.json> --quality studio --azimuth 225 --out <新目录>
```

渲染成功时生成 `纹样三维.png`、有机位时的 `墙地顶人视.png`、贴图已打包的 `同坐标饰面.blend` 与 `饰面三维校核.json`。报告标注来源图案摘要、模式、实际范围、重复尺寸及各视图绑定的构件。三维墙面只在指定的室内正面贴图，地面只贴已校核轮廓，按毫米生成 UV。转角处的安装、材料性能、拼缝和实体色样另行核实。

检查每套渲染中图案是否在预期墙地上、文字是否正向、图案有无被家具挡住，并对照整区平面看门窗和主要走线。默认本地模式会在已选墙艺和地面生成 `本地贴图三维.png`。Blender 失败时也尝试本地贴图，具体渲染状态写入交付记录。所选角度看不到的表面可在平面、试铺或另一视角查阅。默认本地交付提供剖切图，Blender 可进一步出人视和可编辑工程。
