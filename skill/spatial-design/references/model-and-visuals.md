# 模型与表现图

宿主可用已有语言能力把自然语言整理成项目 JSON。有视觉能力时可辅助读取 PDF 预览或描图。布局和预算脚本使用确认的数据执行，可在本机完成。报告只引用程序返回的工位、数量、尺寸和金额。

平面、DXF 和三维来自同一份布局和家具尺寸。快速模式输出两个本地剖切轴测。层高缺失时使用示意竖向轮廓，注明待核。剖切处省略部分墙面以显示室内。

使用 `generate --brief --quality studio --out <目录>` 可在已安装 Blender 的机器上生成材质和阴影更细致的轴测。需要时传 `--blender <可执行文件路径>`。同一批方案用统一视角和比例比较，家具坐标保持一致。输出摘要的 `rendering` 记录实际使用的引擎。Blender 不可用或渲染失败时，一页比选可使用本地轴测继续交付。材质、灯光和家具外观按方案表现处理，按实物选型核对外包尺寸、开门和安装空间。

[室内原创设计](interior-design.md) 可加墙地顶构件及人视机位。人视采用同坐标模型、指定机位和示意平顶，平顶高度采用项目净高。楼板洞口按底图保留。未提供顶面构造时按平顶表达，具体梁、风管、吊顶开口及安装节点在深化图中核对。人视和轴测使用的场景摘要随交付记录。

需要在实际三维中看到墙纸、地板纹样或公司字样时，用 [饰面纹样与试铺](material-patterns.md) 的 `overview --quality studio`。毫米定位跟随已验证的墙艺与地面构件。给用户看固定机位的整区剖切与人视，同时保留可点选的物件和尺寸。

用户明确需要风格灵感时可另作氛围参考，标注用途。一页比选及技术交付采用同坐标模型渲染。

后续接企业 API 时，先确认服务地址、模型名、认证方式、地域和额度，分别联调文字、看图和参考图生图。密钥使用企业受控配置，由授权运行环境读取。接入的模型或供应商需适合处理该项目图纸。接口失败时保留已通过检查的本地输出，把图像生成任务记为待完成。
