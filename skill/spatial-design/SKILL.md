# 空间设计

接受自然描述、宿主提供的语音转写和图纸。用户可以先问设计方向，也可以让 Agent 在已知条件下自行推荐。把用户的原话转换成设计目标、必须满足的条件和可由 Agent 决定的偏好。只补问会改变方案的关键问题，已提供的内容直接沿用。

根据用户当前需要推进：

- **讨论设计或资料不齐。** 直接给出可讨论的空间方向、使用场景和取舍。可以按明确标注的假设做概念推荐。净轮廓、尺寸、出口等关键事实须在计算出图前确认。对话例子和不同场地的判断见 [设计对话](references/design-dialogue.md)。
- **办公、共享办公或创客工作室。** 用 [工作场所设计](references/workplace-patterns.md) 按实际活动、同时到场人数及空间规模选择功能组合。说明方案在日常使用上的差异，再选家具和风格。
- **大面积或多团队整层。** 用 [整层办公与几何核对](references/whole-floor.md) 确认洞口、原有结构、团队工位分区与主通道。根据峰值人数、访客、会议和维护路线主动布置共享配套。先看整区，再给茶水、打印、收纳等容易在全层图中看不清的局部。
- **多建筑园区和大场地。** 使用 [园区总平面](references/campus.md) 建立真实边界、建筑轮廓、道路、入口与分区。运行 `campus` 输出同坐标的总平面、建筑体量和 DXF，检查道路占用及入口连通。再按建筑和楼层分别深化内部空间。
- **原创室内和风格设计。** 先读 [原创设计方法](references/creative-direction.md)，根据需求或用户委托的自主选择发展空间主题、重点构件、材质和灯光。用 [室内原创设计](references/interior-design.md) 写入墙地顶构件和人视机位。要比选时优先做两套在使用、构件组合或材质构成上有差别的方案，保持已确认底图。
- **主动提出物件和风格。** 用 [按需求选择风格](references/style-choices.md) 从使用动作、面积、风格和现场限制筛选物件。可运行 `suggest`，先给少量最适合的组合。用户没列举茶水、收纳、维护等配套时，按场地检查是否需要。每个采用的物件写用途、选型理由、放置条件及需确认的尺寸。
- **判断哪些设施该放。** 按 [设施取舍](references/element-decisions.md) 检查功能覆盖、可复用设施、空间和维护条件。用 `suggest` 或 `office-services` 查看实际的取舍理由。需要新增时进入布局校核。对照方案之间优先解释影响最大的取舍。
- **墙纸、地板与品牌墙。** 用 [饰面纹样与试铺](references/material-patterns.md) 确定纹样、方向、模块和收边。可用生图、授权样图或本地原创绘图。品牌字样按用户提供内容另行排版。绑定已校核的墙艺或地面后，`deliver --brief` 可直接用本地贴图三维，`--quality studio` 可追加 Blender 和有机位时的人视。比选保持统一视角并复核比例。
- **日常配套、绿化和装饰。** 设计办公全区时，用 [日常配套与装饰设计](references/daily-use.md) 主动检查饮水、垃圾与回收、入口寄放、收纳和保洁，按用途补上打印、充电、导视、会议、展示和绿化。底图只确认原状。将拟新增且条件适合的设施写进布局，用 `office-services` 和整区总览核对缺项、分布、操作面及现场条件。
- **理解整区和每件物品。** 按 [整区设计与逐件查看](references/whole-space-overview.md) 从空间用途主动核对功能。优先用 `overview` 交付全区分区平面、整体剖切三维和可点选的逐件视图。已知原状、拟新增和待确认内容按实际输入标明，局部人视用于补充。
- **生成或比较方案。** 使用本技能目录的 `scripts/run.py`。脚本路径可用绝对路径。环境设置与输入字段见 [项目输入](references/project-input.md)。
  1. 把实际尺寸、规则出处、固定设施、家具及分区需求写入项目 JSON。按用户要求区分必须满足的条件和可以取舍的偏好。把指定净宽的走线、从指定入口到达的门前位置、需锁定的家具位置录入约束。使用项目认可的通行要求。报价采用用户提供或可核实的价格。
  2. DXF 用 `inspect` 检查图层和单位，再用 `import-dxf` 导入明确映射的图元。PDF、截图、手绘及照片按 [图纸读入](references/drawings.md) 预览、描图和校准。用 `preview` 对照原图和已知尺寸，确认净轮廓、单位、出口、固定结构和禁占区后设置 `geometry.confirmed`。
  3. 默认用 `generate --brief` 出一页比选与图纸包。已安装 Blender 且用户重视材质和空间表现时，加 `--quality studio`。先搜索，再按 `ready / partial / no_layout` 报告结果。已有手工排好的候选可用 `--layouts` 原坐标校核。无法通过时指出冲突和可调整项。
  4. 用 `verify` 检查方案包并读取几何对齐记录。先给一页比选，说明推荐和最关键的取舍。对照平面和三维核查洞口、门窗、固定结构和家具。面积紧张且候选只相差少量移位时，可以集中比较两种不同用法。把同版本 DXF、几何核对、布局数据、清单与详细视图放在 ZIP，详细报告可省略 `--brief`。
- **交付给使用者按图摆放。** 按 [推荐方案交付](references/design-delivery.md) 对推荐或用户选定方案运行 `deliver`。以「先看这里」和整区总览为入口，附同编号摆放表、底图核对点、毫米平面和对应三维。只有确认现场可对应的基准点、比例与物件尺寸，才能用坐标落位。
- **继续调整。** 识别用户选择的方案及变更，沿用已确认条件。用 `revise` 在新目录重算并复核。更换空间边界或固定结构时重新确认几何。
- **采购、交底或交付使用。** 用户选定方案后按 [采购与安装交底](references/procurement.md) 运行 `procure`。给出可询价规格、数量、同编号定位图和现场接口，按实测、选型、施工和验收的完成程度说明当前状态。

三维效果使用与 DXF 相同的布局数据。渲染、材料和概念参考的使用见 [模型与表现图](references/model-and-visuals.md)。建筑、消防、结构及机电条件保留专业复核状态。跨客户端安装、语音转写及无脚本环境的用法见 [宿主兼容说明](references/portable-hosts.md)。
