# 推荐方案交付

用户提供原图和需求即可开始。先确认空间用途、人数、必须保留的结构与物件。按 [图纸读入](drawings.md) 核对单位、净尺寸、门洞、窗、固定结构和禁占区。图纸缺少比例或关键尺寸时，先给概念方向、底图核对图和需要用户补的尺寸。墙顶和机电的缺项列出待核范围。

对已确认的平面，先找设施需求、现有可复用的设施和用户限制，安排可用的布局。用 `generate --brief` 生成候选。优先项并列时说明并列原因，指出所选布局适合怎样使用。没有通过校核的候选时说明具体冲突和能改动的条件。

```powershell
python scripts/run.py generate <项目.json> --brief --out <候选方案目录>
python scripts/run.py deliver <候选方案目录> --out <推荐方案交付目录>
```

`deliver` 会重新校核源方案并使用已核验的推荐结果。用户已有选择时加 `--option B`。已有整区说明可用 `--brief <整区说明.json>`，其编号及布局摘要应对应所选版本。用户需要贴图和人视时加 `--quality studio`。找不到 Blender 或无法渲染时，交付页显示本次渲染状态。

## 阅读顺序

1. 先打开《先看这里》确认方案、选用理由和待核条件。
2. 打开《整区总览》看平面和同一布局的三维。点击物件或搜索编号，可查看尺寸、所在区域以及拟布置与保留状态。遇到全层办公，用配套局部图补足小物件细节。
3. 在平面中找 A、B 两个底图轮廓点，在现场确认是同一位置及同一方向，并复核其直线距离。可从 A 按图上的 X、Y 方向量取毫米坐标。斜墙和不规则轮廓沿图纸轴线量取。两点被遮挡、不可识别或无法复尺时，请项目方提供可核对的现场轴线或基准。
4. 《逐件摆放.csv》和总览共用编号。家具和地面按轮廓点定位，墙面按线段两端及标高定位。带可识别使用侧或朝向的物件，在选中时显示橙色标线。尺寸较长的多边形和设备点位同时可在毫米 DXF 复核。型号变化时按新外廓重新校核操作面和通行。

交付清单的文件摘要和布局版本用于复核。文件内的设计坐标与标高依赖输入的底图和选型尺寸。结构改造、给排水、电气、固定节点、疏散及验收按项目的现场和专业资料进一步确认。
