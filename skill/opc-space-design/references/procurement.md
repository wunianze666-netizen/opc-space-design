# 采购与安装交底

按确认的方案交付。先说明空间如何使用、各区采用哪些墙地顶做法，再把家具、定制构件、饰面与配套拆成能询价和验收的项目。已有设施单独核实保留、改造或替换。实际方案缺尺寸时先列对应复尺项，保留能确认的选型资料。

从已校验的方案包生成尺寸、数量和定位。

```powershell
python scripts/run.py procure <方案包目录> --option A --out <采购目录>
```

先用采购清单的采购号找尺寸与规格，再用定位图和安装定位表找具体位置。图上可用采购号识别同款，DXF 和定位表保留逐件编号、平面坐标和标高。家具外包尺寸由实际模型轮廓和高度计算。组合家具的可购部件分别列出。定制件用整组外包及安装标高询价，确认附带的背板、饰边、固定件或灯具配套。不同地面饰面按净铺面积拆分，供货数量由现场排版、裁切和包装规格确定。

## 下单与施工衔接

1. 复尺外轮廓、门窗、净高与安装面。确认实际进场路线、门洞、电梯和拆装后的最大包装尺寸。
2. 向供应商索要准确的外包、活动件展开尺寸、型号、安装条件、颜色样板和报价。打开门、抽屉、拉椅后应满足设计使用空间。尺寸或位置变化后重新校核。登记供货单位及含税、安装、运费范围。
3. 冻结水电、网络、照明、空调、门禁和消防等现场接口。对工位、通话舱、茶水或其他设备确认相应点位、供电和接入条件。定制墙顶项目按现场基层、支撑和专业深化图确认。
4. 按确认样板核对饰面，安装后按编号复核数量与落位，检查开门、通行和使用功能。机电系统按适用的项目流程完成调试和验收，随后确认可交付使用。

`ready_for_quote` 表示从该版布局可提取询价资料。现场复尺、供应商选型、专业图纸、系统调试和验收分别留痕。保留采购交底内的布局摘要，后续变更时从新方案重出清单。
